# Contextual Retrieval Research

Reproducible experiments for Anthropic's *Contextual Retrieval* (2024): dataset adapters, lexical/vector/hybrid baselines, retrieval metrics, audit trails, and contextual indexing.

Implementation is staged; see [research roadmap](docs/00-roadmap.md) on the research branch once available.

Primary references: [Anthropic article](https://www.anthropic.com/research/contextual-retrieval) and [Claude cookbook](https://github.com/anthropics/claude-cookbooks/tree/main/capabilities/contextual-embeddings).
