## Defects found and fixed on the final stacked integration branch

1. **Stale contextualization cache (high)**: prompt-version alone did not invalidate a cache when someone edited the actual Prompt template but forgot to increment the version. The Anthropic prompt text now has a SHA-256 fingerprint in the cache key and context bundle manifest. Metadata control has an explicit fingerprint.
2. **Insufficient SciFact source pinning (high)**: download enforcement relied on upstream MD5 only. It now additionally pins a SHA-256 value from a successfully verified official archive. The MD5 is retained for compatibility/provenance, but no longer the only acceptance criterion. ZIP path traversal, symlink and extracted size guards remain.
3. **Reranker evidence contamination (high)**: the Runner validated only the count of returned results, not that every ID belonged to the exact retrieved pool or was unique. Both fixed and Cookbook modes now verify membership, unique IDs, contiguous ranks and finite scores. Cohere returned indices must be exact integers and relevance scores finite.
4. **Partial artifact publication (high)**: a run could write a succeeded manifest before writing its rankings. The Runner and Contextualization Engine now stage complete records and publish the directory only after successful serialization; failure removes the staging directory. No previously completed result is overwritten.
5. **Voyage embedding direction/cache mix-up (medium/high)**: explicit query/document input modes were not independently supported and identical texts could be incorrectly shared if operators intended asymmetric input types. Add --embedding-input-mode legacy|asymmetric and persist its value in run manifests. Distinct input modes produce distinct content-hash cache keys; repeated texts within one API batch are deduplicated. Legacy no-prefix behavior stays the default for historical method comparison.
6. **Nonfinite and malformed retrieval values (medium)**: reject NaN/Infinity in vector embeddings and dot product, and invalid Cohere scores/indices. Reject invalid dimensionality and malformed provider vectors before caching.
7. **Artifact replay provenance (medium)**: the analysis loader already recomputed ID metrics and aggregates but trusted the saved rank fields and rerank provenance. Now reject duplicate ranked IDs, inconsistent one-based ranks, nonfinite saved scores, and reranked IDs absent from the recorded candidate pool.
8. **Regression tests**: add dedicated offline tests that exercise all above negative paths, including simulated write failures, checksum mismatch, cache separation, bad rerank outputs and tampered ranking artifacts.

## Historical and scientific boundaries (not fixed by code changes)

- No billable Claude, Voyage or Cohere model experiments were executed in CI, and the 2024 historical model snapshots may be unavailable. E04/E06/E08/E10 remain implementation pathways, **not completed official accuracy reproduction**.
- Existing Anthropic experiment outputs are from the pinned 90-document / 737-Chunk / 248-Query Cookbook corpus. They do not by themselves reconstruct the paper's unreleased multi-domain benchmark.
- The metadata-context E05 run is a *deterministic control*. It is not an approximation to the semantic context generated by Claude.
- The BEIR SciFact extension uses 5,183 complete documents and document-level Qrels with binary relevance; its NDCG is not the published graded BEIR NDCG. Do not compare its raw scores to Anthropic Chunk Recall.
- Elasticsearch explicitly tie-breaks equal scores by Chunk ID; local Python BM25 is a separate, differently analyzed baseline.
- Provider usage/cost statistics require a complete, sourced workload ledger. Unprovided costs are never zero. SQLite and JSON embedding caches are designed for sequential local runs, not uncoordinated concurrent writers.
- Prompt fingerprints distinguish templates but not hidden model changes behind the same hosted model identifier. Explicit revision-aware model metadata is required for exact historical recreation.

5. Download official SciFact with pinned MD5+SHA256, validate 5,183 docs/300 Queries, run E02 BM25 and generated report.
6. Ensure all four PRs are GitHub mergeable with successful CI and no unaddressed blocking review threads.
7. Merge using GitHub's commit-preserving merge method in strict #1, #2, #3, #4 order after retargeting each descendant PR to main. Recheck final main CI and verify combined source content and ancestry.

## Quality assurance result

The dedicated review tests are separate from the earlier historical correctness tests. A successful set of tests means the *offline execution and safeguards* are exercised. It does not prove that a paid model produces the same score reported in Anthropic's 2024 paper.
